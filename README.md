Данный проект был реализован в качестве дипломной работы в 2025 году в Московском авиационном институте.

**Тема**  
Прогнозирование фондового рынка с помощью нейронных сетей  

**Задание и исходные данные к работе:**  
Необходимо разработать модель, прогнозирующую динамику фондового рынка с использованием нейронных сетей и глубокого обучения для повышения точности предсказаний изменений рыночных цен. В качестве методов разработки использовать средства прогнозирования временных рядов на базе специализированных пакетов и нейронных сетей глубокого обучения. Реализацию приложения проводить с использованием языка программирования Python и его специализированных библиотек, включая библиотеку PyTorch. Интерфейс приложения должен быть разработан с использованием FastAPI.
